# CoderHaveli

CoderHaveli is an interactive coding platform that provides high-quality tutorials, courses, and coding challenges to help developers enhance their skills.

## Features
- 📚 **Tutorials & Courses**: Learn programming languages and frameworks like JavaScript, React, Node.js, and more.
- ⭐ **Testimonials**: Read what our users say about CoderHaveli.
- ❓ **FAQs**: Get answers to commonly asked questions.
- 🎨 **Modern UI**: Built with React and Tailwind CSS for a seamless user experience.

## Technologies Used
- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express.js (if applicable)
- **Database**: MongoDB (if applicable)
- **Deployment**: Vercel/GitHub Pages

## Installation
To set up the project locally:
```sh
# Clone the repository
git clone https://github.com/PrashantSharma0512/CoderHaveli.com.git

# Navigate to the project directory
cd CoderHaveli.com

# Install dependencies
npm install

# Start the development server
npm start
```
